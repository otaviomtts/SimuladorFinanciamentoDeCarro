# Financiamento de Carros (Java Swing)

Simulador de financiamento de veículos feito com Java Swing.

## Como executar no IntelliJ IDEA
1. File > Open... e selecione a pasta do projeto (onde está o `pom.xml`).
2. Aguarde o Maven importar o projeto.
3. Abra `src/main/java/br/com/concessionaria/FinanciamentoCarros.java`
   e clique no botão verde ao lado do método `main`.

Requisito: JDK 11 ou superior.
